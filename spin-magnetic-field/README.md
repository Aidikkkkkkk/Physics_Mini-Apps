## Внимание!

Приложение сделано только для Windows.

Приложение показывает прецессию спина , например электрона , в магнитном поле в зависимости от t - времени и B - магнитной индукции по 3 компонентам

1. Распаковать zip
2. Запустить `quantum.exe`
3. Понажимать кнопочки, порадоваться, что вы увидели, как спин прецессирует в реальной жизни, не зная, что такое спин (это можно загуглить)
4. Если прям интересно, в `Solution` приведено решение
